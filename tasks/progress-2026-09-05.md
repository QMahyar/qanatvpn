- Windows engine exe path mismatch (every connect fails)
- Android store writes fail (HOME/USERPROFILE unset)
- No LICENSE file (AGPL claims unbacked)
- build-android CI never produced APKs
- gh-pages never deployed (latest.json 404)
- Subscriptions one-shot imports (goal.md lock broken)
- No server selection, no settings, wizard restarts every launch

### Security gaps found
- No kill-switch on any platform
- Private keys leaked in logs and temp files
- Update artifacts have no hash verification
- HTTP subscription URLs expose credentials

### Production gaps found
- README is untouched flutter create template
- Windows release unsigned
- Debug-signed APKs only
