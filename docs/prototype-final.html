Step 1/3VPN permission

Allow VPN connection

Android will show a system dialog: “yourvpn wants to set up a VPN connection.” This creates one tun for all traffic. No external app needed.

System dialog preview • VpnService

Keep VPN alive in background

Android Doze can pause the tunnel. Allow “Don’t optimize” for yourvpn. This is an acceptable use for VPN and network tools and keeps the foreground service alive. You can change it later in Settings.

isIgnoringBatteryOptimizations() → requestIgnoreBatteryOptimization()

Who uses the VPN

Choose allowlist (only these apps) or bypass (these apps skip VPN). Like Slipnet per-app. You can change later.
